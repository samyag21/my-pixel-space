# My Pixel Room - 3D Interactive Portfolio

An interactive, isometric 3D room built entirely with HTML, CSS, and Vanilla JavaScript. No external 3D libraries or frameworks.

## Live Demo
https://samyag21.github.io/my-pixel-space/

## Features
- Drag and rotate the room in 3D space
- 4 dynamic neon themes toggled via the lamp
- Custom cursor particle effects based on the active theme
- Interactive monitor with a glitch effect and file menu
- Hidden easter eggs (cat under the desk)
- Day/Night mode toggle

## A Note on How This Was Built
This is my first "vibe coding" project. I used AI as a pair programmer to help me learn and push past the limits of what I already knew. I did not write every single line from scratch. Instead, I focused on understanding the 3D CSS concepts, tweaking the logic, and designing the experience. It was a massive learning experience in how to prompt, debug, and ship a product that feels alive.

## How to Run Locally
1. Clone the repository.
2. Open index.html in your browser.
